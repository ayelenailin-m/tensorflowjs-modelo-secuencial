# TensorFlow - Modelo Secuencial Simple 

Este proyecto consiste en un sitio web simple que entrena un modelo de regresión lineal usando **TensorFlow.js** para predecir el valor de `y` en base a la fourmula `y=2x+6`.

## Se usó
- HTML
- TensorFlow.js (via CDN)
```html
<script src="https://cdn.jsdelivr.net/npm/@tensorflow/tfjs"></script>
```
---

## Ejecución
1. Claná este repositorio
2. Abre `index.html` en tu navegador o abrí con Live Server
3. Prueba el modelo
